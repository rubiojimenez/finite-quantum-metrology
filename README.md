# Non-asymptotic quantum metrology

This repository contains the LaTeX source of a curated version of my PhD thesis and the code developed as part of it.

> J. Rubio Jiménez, *Non-asymptotic quantum metrology: extracting maximum information from limited data*, PhD thesis, University of Sussex (2020). Available as **arXiv:1912.02324** and **EThOS: uk.bl.ethos.801042**.

The code implements a finite-sample approach to quantum metrology. Although originally written for the examples presented in the thesis, it can be adapted to a wide range of quantum metrology problems.
